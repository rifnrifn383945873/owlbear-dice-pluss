# 주사위+ (Owlbear Rodeo 확장)

주사위를 **더하거나 빼고**, **상태 보너스를 여러 개 켜서 중첩**하고, **목표값으로 성공·실패를 판정**하는 Owlbear Rodeo 확장입니다.

## 기능

- d4 ~ d100을 **더하기(+) 칸**과 **빼기(−) 칸**에 따로 넣어요. 예: `1d20 + 1d6 − 1d4`
- **상태 보너스**: `축복 +1d4`, `중독 -2`, `엄폐 +2`처럼 저장해 두고 체크한 것만 모두 더해져요.
  - 값 형식: `+2`, `-1`, `+1d4`, `-1d6`, `1d6+1`, `2d8-1d4`
- **능력치**: 힘·민첩 같은 스탯을 저장하고, 게임 중 −/+ 버튼이나 숫자 입력으로 언제든 바꿔요. 바꾼 값은 다음 굴림부터 적용돼요.
  - 판정 칸에서 능력치를 고르고 방식을 정해요: `보정치로 더하기`(D&D: 16 → +3), `값 그대로 더하기`, `목표값으로 쓰기`(CoC: 값 이하면 성공)
  - 상태 보너스 값에 `+@숙련`처럼 쓰면 그 능력치의 현재 값이 더해져요.
- **고정 보정치**, d20 **유리·불리**
- **판정**: 목표값과 `이상이면 성공`(D&D식) / `이하면 성공`(CoC식), d20 1개일 때 자연 20·1은 대성공·대실패 표시
- **공유**: 굴리면 방의 다른 사람에게 알림이 뜨고 굴림 기록에 남아요. `나만 보기`를 켜면 공유하지 않아요.
- 상태 보너스와 설정은 각자 브라우저에 저장돼요.

## 설치 (GitHub Pages로 무료 호스팅)

Owlbear Rodeo 확장은 인터넷 주소(HTTPS)에 올려 둔 `manifest.json`으로 설치해요. 방의 모든 사람이 그 주소에서 불러오기 때문에 내 PC(localhost)에만 두면 다른 사람은 못 써요.

1. GitHub 계정을 만들고 새 저장소(Repository)를 만들어요. 예: `owlbear-dice-plus`, **Public**
2. 이 폴더의 파일 5개를 저장소에 올려요: `manifest.json`, `index.html`, `background.html`, `shared.js`, `icon.svg`
   - 웹에서 **Add file → Upload files**로 끌어다 놓으면 돼요.
3. 저장소 **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)**로 두고 저장해요.
4. 1~2분 뒤 주소가 생겨요: `https://<내 아이디>.github.io/owlbear-dice-plus/`
5. Owlbear Rodeo 방에서 왼쪽 위 **방 메뉴 → Extensions → Add Custom Extension**에 아래 주소를 넣어요.

```
https://<내 아이디>.github.io/owlbear-dice-plus/manifest.json
```

6. 방 위쪽 확장 막대에 **주사위+** 아이콘이 생겨요.

## 사용법

1. 굴릴 주사위의 **+ 칸**에서 개수를 늘려요. 빼야 하는 주사위는 **− 칸**에서 늘려요. 각 칸의 `−` 버튼으로 개수를 줄여요.
2. 상태 보너스를 체크해요. 새 효과는 이름과 값을 적고 **추가**를 눌러요.
3. 판정이 필요하면 목표값을 넣어요.
4. **굴리기**를 눌러요. `굴릴 식`에서 미리 식을 확인할 수 있어요.

## 수정했을 때

파일을 고친 뒤 다시 올리면 돼요. 바뀐 게 안 보이면 `manifest.json`의 `version`을 올리고 확장을 지웠다가 다시 추가하세요.
